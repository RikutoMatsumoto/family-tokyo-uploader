Privacy Policy - family-tokyo-uploader

family-tokyo-uploader is a personal, single-user desktop tool used only by its developer to upload videos to the developer's own YouTube channel via YouTube API Services.

  • This tool does not collect, store, or share any personal information from any third party.
  • It accesses only the developer's own YouTube account through Google OAuth 2.0. OAuth tokens are stored locally on the developer's personal computer and are never shared with anyone.
  • This tool uses YouTube API Services. Users of this tool agree to be bound by the YouTube Terms of Service. See also the Google Privacy Policy.
  • No YouTube API data is stored after the upload process completes. No data is displayed to any user. No cookies or tracking are used.
  • You can revoke this tool's access to your Google account at any time at https://myaccount.google.com/permissions.
